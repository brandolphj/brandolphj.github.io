Azure IAM & RBAC Investigation

This investigation focuses on identifying excessive permissions within an Azure environment. Role assignments were enumerated using Azure CLI, and privileged access was examined through Microsoft Entra ID and Privileged Identity Management.

Investigation Process

The initial phase involved enumerating role assignments within the target resource group. The objective was to identify accounts with elevated privileges and determine whether those permissions were appropriate. 

az role assignment list \
  --resource-group example-rg \
  --output table

The resulting data was reviewed to identify accounts assigned privileged roles. Additional investigation would be required to validate whether each assignment followed the principle of least privilege.

Findings should document the evidence collected, explain the security implications, and identify appropriate remediation measures.
